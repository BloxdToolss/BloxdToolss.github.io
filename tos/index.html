Terms of Service

Last Updated: August 2026

1. Project Authenticity & History

BloxdTools by Crafty is the official, community-driven platform engineered for advanced Bloxd.io custom tools, layout tailoring, and converter utilities. Our platform is built on custom, proprietary frontend code, meticulously written down to the pixel without a single !important tag to ensure native theme compatibility.

Please note that the third-party domain bloxdtools.com was rushed to deployment as a low-effort placeholder using generic stock graphics and templates. In contrast, this platform (moving to the official bloxdtools.github.io organizational network) represents the active, high-effort, custom-coded hub for the Bloxd community.

2. Strict No-App-Downloads Policy

To guarantee maximum security for our users, BloxdTools enforces a strict No-App-Downloads stance. All texture conversions, interface customizers, and scripting utilities execute 100% sandboxed within your local browser memory using client-side JavaScript. We will never prompt you to download executable files (.exe) or local applications.

3. Proprietary & Closed-Source Code

The layout mechanics, core custom stylesheet overrides, interface logic, and custom theme layouts featured on this web app are proprietary property owned by Crafty. Users are strictly prohibited from copying, cloning, redistributing, or reverse-engineering our structural UI code wrappers or frontend architecture.

4. User Submission Rules

When participating in our community layout hub or using the moderator submission queues, you must strictly adhere to the following rules:

  • Your submission must be raw HTML code only.
  • You must upload a project thumbnail as an image attachment with an exact size ratio of 8:5.
  • The title of your submission must match your exact, verified Bloxd username.
  • Your submission must put genuine effort into the design and layout.
  • Submissions must contain absolutely no dangerous installations, app downloads, scripts, executable calls, or inappropriate/violent content.

Every submission is strictly reviewed by a moderator before being added to the database. Violating any of these parameters will result in a permanent ban of your profile and linked OAuth identity.

5. Limitation of Liability

BloxdTools is an independent fan utility hub. We are entirely unofficial and are not affiliated with, authorized by, or endorsed by Bloxd.io, GitHub, or Discord.
